# 3zT Browser

متصفح خفيف مبني على Chromium (عبر Electron)، بواجهة شفافة طافية في نص الشاشة وفيديو خلفية في صفحة التبويب الجديد.

## التحميل
من صفحة **Releases** نزّل `3zT-Browser-…-win-x64.zip`، فكّه، وشغّل `3zT Browser.exe`.

## وش فيه (النسخة 0.1)
- شريط علوي شفاف في المنتصف: رجوع، للأمام، تحديث، شريط بحث Google، المفضلة، الإضافات، التبويبات، القائمة.
- أزرار النافذة في الزاوية حسب اللغة (يسار بالعربي، يمين بالإنجليزي).
- صفحة التبويب الجديد (ساعة، تاريخ، بحث، اختصارات، ثيمات وفيديو).
- البحث دائماً في Google.
- تحميل إضافات كروم من مجلد (content scripts، service worker…).
- توفير الذاكرة: التبويبات الخاملة تنام وتفضّي الرام.
- استرجاع التبويبات عند الفتح، واستيراد المفضلة من كروم.

## للمطورين
```
npm install
npm start
```
بناء نسخة ويندوز محمولة: `scripts/build-win.sh electron-v45.1.0-win32-x64.zip`

## الملفات
- `src/main.js` العملية الرئيسية: النافذة، التبويبات، الإضافات، الذاكرة.
- `src/ui/` الشريط الطافي.
- `src/newtab/` صفحة التبويب الجديد.
